官方原文：[MIT 公告列表](https://scioperi.mit.gov.it/mit2/public/scioperi)。行政范围是公告登记事实，不代表区域内每个服务都停运；DIRECT_SERVICE 指公告主体包含运营服务，不代表所有列车取消。Toscana TPL 仍没有可靠的具体钟点，继续保留未知。

Foggia/Udine 既有 `region=UNKNOWN` 只用于旧存储/路由兼容。新的官方地域与 locationStatus 已明确地点已知、网站暂未支持；城市入口仍为 20 个，没有增加前端页面。

Legacy 行的 data_source=LEGACY_REVIEW、无 source_key，因此不属于 MIT 完整快照的自动退役候选。本次只将这一行改为 STALE，保留历史及关联记录，没有永久删除。

## 增量数据合同

仍使用原 `timing_evidence.fields` JSON 列，无新 schema 迁移：

- officialGeography：官方 region / province / relevance 及原文来源。
- supportedCityProjection：本站支持城市的投影，与官方完整范围分离。
- locationStatus：支持城市、未支持城市、未支持区域、未能投影、真正未知地点分开。
- railSections：运营铁路、铁路外包、货运分别保留，标明是否由当前事件表示。
- scopeType 新增 RAIL_GENERAL；纠正 subtype 时同步 passengerImpact，避免证据内部不一致。

聚合 API 保留底层事件，并输出 officialGeography 和 supportedCityProjection。来源链接仍在既有底部来源区，计数逻辑没有修改。

## Jev 与队列

semantic-v5 将官方行政范围及支持城市投影带入审核，不要求 Jev 补造不在 registry 的城市。
任何遗漏、扩大、冲突或重复疑点 >=0.80 都进入 NEEDS_REVIEW，不被低 subtype 置信度遮蔽。高置信矛盾保留 FLAGGED；自动更改仍需 >=0.97 且存在独立官方证据。时间计算、日期、保障区间计算继续由代码负责。

`npm run review:queue` 读取服务端持久审核缓存，不调用付费模型。它只统计当前审核版本，按 source_key 的最新结果去重，最新 AGREES 清除旧提醒，排除过期事件；没有公开管理接口或网页审核后台。

本次实际生产审核 26 条：11 AGREES、15 INCONCLUSIVE、0 自动纠正、0 FLAGGED、0 NEEDS_REVIEW、0 调用失败。队列当前为空，不代表绝对准确。修正规则和审核输入后，Toscana 的遗漏概率为 0.53、Bologna 为 0.35；不要把旧版本约 0.84 的历史结果混入当前统计。测试覆盖 0.84 遗漏、0.71 subtype 仍进入队列的情况。

## 更新与成本

既有每天 05:00 UTC 定时同步保持，未增加每小时调用、未升级付费计划。源文本与解析结果的 hash 加审核版本组成缓存键，24 小时缓存；每次最多 30 个付费审核、55 秒 QA 期限。不是全网实时监控。

固定月度数据库预算 USD 0.20 不变，调用前原子预留，不能由环境变量调高；报价不明或涨价则不调用。October ledger 累计 4267 microUSD，即 USD 0.004267（含保守预留取整）。随后读取 26 个缓存结果全为 cached，前后账本均为 4267，没有增加模型费用。

该限额仅覆盖后台 QA；Claude 的未来公开 Ask 必须接入同一账本才能承诺全站 AI 合计限额。域名/既有托管费用不属于此 AI 预算。
