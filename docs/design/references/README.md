# 改版参考对照（2026-10-04）

截图来自各 App 在 App Store 上的官方页面，仅供内部学习，不提交进仓库（见同目录 `.gitignore`）。如需重新下载，在本目录下执行 `docs/design/references/fetch.sh`。

| 我们的模块 | 参考 | 具体页面 | 学什么 | 怎么迁移 |
|---|---|---|---|---|
| 整体基底 | Apple 天气 | 城市详情页（`apple-weather-2`） | 背景是随天气和时段变化的天空；内容放在半透明玻璃卡片里，卡片有小标题和细分隔线；全部用白字；大号数字用极细字重 | 背景跟随**所选日期的状态**和**罗马当地的昼夜**：平静日是晴空，罢工日是阴天，夜里是深蓝。这就是"罢工天气"这个隐喻 |
| 首屏状态 | Apple 天气 | 详情页大标题（`apple-weather-2`） | 小号地点标签 → 城市名 → 超大细体数字 → 天气描述 | 城市名 → 超大细体的"5 天"（距下次罢工）或"停运中" → 一句说明 |
| 未来概览的时间条 | Apple 天气 | 10 日预报（`apple-weather-2`） | 每一行的范围条都画在**同一个刻度**上，当前时刻用一个点标出 | 当日看板里，每种交通的时段条共用一条 05:00 到末班车的刻度 |
| 日期轨道 | Apple Sports、Transit | 比分列表（`apple-sports-2`）、班次卡片（`transit-2`） | Sports：所有行等高，重点靠发光和颜色而不是靠尺寸；Transit：等宽卡片，选中的卡片实心填充，并带一个指向下方内容的缺口 | 所有格子一样宽；罢工日是玻璃填充加状态图标，平静日是透明的；连续平静日折叠成一个同宽的格子；选中格用实心白底加向下的缺口，指向当日看板 |
| 跨天罢工 | Apple 日历 | 跨天日程条（参考常识） | 一条连续的横条跨过两天 | 两个格子底部用一条连续的细线连起来；看板里把两天的时间条并排放在一起，中间画午夜分隔线 |
| 当日看板 | Flighty | 机场状态卡（`flighty-5`） | 卡片标题 + 右侧状态值；图标 + 彩色状态标题 + 一句解释；底部一行注明发布机构；正常的项目用绿色"Normal Operations" | 每种交通一行：图标、名称、右侧相对时间，下方是彩色状态句；未受影响的交通显示"正常运行"；卡片底部一行注明"来源：意大利交通部 MIT · 更新于…" |
| 多交通时间对比 | Transit | 路线比较（`transit-4`） | 顶部一条共享的时间刻度加竖直网格线，每条路线的色块按时间摆放 | 当日看板顶部只放一次刻度，竖直网格线贯穿所有行 |
| 线路标识 | Transit、Citymapper | 附近线路（`transit-1`）、推荐路线（`citymapper-3`） | 官方线路色块；多条线路用"·"连接 | 米兰 M1–M5 使用官方颜色；AI 问答里写成"你提到的：M1 · S5" |
| AI 问答结果 | Citymapper | 推荐路线（`citymapper-3`）、行程详情（`citymapper-4`） | 每一行：线路徽标、右侧大号数值、下方次要说明；实时数据旁有一个小信号图标 | 按"你提到的交通"分组，每组复用当日看板的行组件；由程序计算出的事实标"规则"，由模型判断的标"Jev" |
| 工具入口 | Apple 天气 | 详情页底部的小方块模块 | 2×2 的方形小卡片，每张只讲一件事 | 小组件、日历订阅、添加到主屏幕、支持与反馈，各占一张方块卡片 |
| 底部操作 | Apple 天气（iOS 26） | 底部悬浮的玻璃按钮（`apple-weather-2`） | 悬浮的玻璃胶囊和圆形按钮 | 居中的 AI 输入胶囊，右侧一个圆形按钮用来切换城市 |
| 弹层 | Apple 天气 | 地图页的图例和时间轴面板（`apple-weather-3`） | 半透明面板、圆形关闭按钮、紧凑的标题 | 所有二级页面统一使用一个玻璃底部弹层 |
| 动效 | Apple 系统动效 | — | 切换内容时短暂模糊再变清晰；弹簧动画带一点点回弹 | 切换日期时看板模糊淡入；选中指示器沿轨道滑动；弹层用略带回弹的弹簧；如果用户开启了"减弱动态效果"，全部关闭 |
