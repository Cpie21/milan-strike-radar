# 前端改版 v3：回到产品本身（2026-10-05）

v2 照搬了 Apple 天气的形态（天空背景、首屏大数字、方块工具卡），偏离了这个产品已经验证过的判断。v3 的原则：**参考只借用能服务我们用户诉求的部分**。

## 作品集里已经验证的判断（不能推翻）

| 判断 | 来源 | v3 的做法 |
|---|---|---|
| 消除首屏冗余分区，打开就是日期加罢工卡片 | 作品集 · 迭代决策 01 | 去掉首屏大数字和"今天概览"；首屏 = 标题 + 日期轨道 + 当天卡片 |
| 正向点选跳转，不做反选筛选 | 迭代决策 02 | 恢复交通类型的快速跳转按钮，只显示当天有罢工的类型 |
| 当日进度条回答"现在罢工还在进行吗，影响我现在和之后的行程吗" | 特色功能 | 卡片内的时间进度条带"现在"标记；当天显示"进行中 · 15:00 恢复" |
| 涂鸦是情绪出口，也是传播窗口 | 特色功能 | 分享和"我受影响了"在每张罢工卡上**始终外露**，不收进折叠区 |
| 82% 的访问来自直链分享；埋点验证"是否愿意传播与表达" | 产品价值验证 | 分享和涂鸦是一级操作；每种交通保持独立卡片，因为涂鸦计数按交通分组 |
| 装饰分散对关键信息的注意力 | AI 稿的判断标准 | 不用天空背景、不用氛围渐变；颜色只表达状态 |
| 工具感：状态清晰直接，各板块视觉一致 | 落地方案 | 统一的深色实底卡片、一种圆角、一套状态色 |

## 弹层规则

- 内容一屏放得下：弹层高度自适应，不显示拖动条，右上角关闭；仍可下滑关闭。
- 内容超过 60% 屏高：先以 60% 打开并显示拖动条；上拉展开到接近全屏；展开后内容才可以内部滚动；下拉收起，再下拉关闭。

## 页面结构（自上而下）

1. 顶栏：意大利罢工查询 / DEVELOPED BY 21°C · 添加到桌面 · 城市
2. X月罢工信息 · 选择日期
3. 日期轨道（等宽格；连续的平静日折叠；跨天罢工连线）
4. 快速跳转（只显示当天有罢工的交通类型）
5. 罢工卡片：标题、主体与状态 → 大号时段 → 状态胶囊 → 进度条 → 保障时间段 / 受影响线路（信息网格）→ 分享 · 我受影响了（始终外露）→ 涂鸦 → 来源
6. 无罢工日：无交通罢工 / 安心出行，加一行"下一次罢工"
7. 工具：添加小组件 · 同步日历（一行一个按钮）
8. 支持作者
9. 底部悬浮：一句话问罢工
